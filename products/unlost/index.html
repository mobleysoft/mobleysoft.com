UNLOST 0.2 Verified local alpha

Everything you can prove, one command away.

Unlost is a private search and retrieval primitive for a person, shell pipeline, or AI agent. It separates finding, searching, resolving, and hydrating so every result can carry provenance instead of guesswork.

Request the $1 launch edition Machine-readable status
01

Find

Exact filenames and paths, without false positives from words inside unrelated documents.

unlost find contract.pdf
02

Search

Relevance-ranked text across declared files and Codex or Antigravity JSONL histories.

unlost search "decision context"
03

Resolve

Choose the authoritative duplicate using declared source roles, hashes, timestamps, and live verification.

unlost resolve ventures.json
04

Hydrate

Read regular files and ZIP or tar members only when their content is actually needed.

unlost hydrate archive.zip#notes.txt
05

Connect

Bring MBOX mail exports and mounted Drive folders into the same provenance-preserving search field.

unlost connector import-mbox All-mail.mbox
06

Run

Search through a localhost-only interface while optional bounded index pulses remain attached to your terminal.

unlost serve --grow --open
