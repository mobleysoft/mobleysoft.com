# Vertical Slice: The Second Arrival

## Purpose

The slice proves the unique causal loop, not the eventual quantity of content.
It is complete only when the same loop works on desktop and touch input through
the deployed Mobleysoft homepage.

## Player Loop

1. Warm in outside the readable sheath.
2. Use inertial flight to convert approach into a controlled surf.
3. Hold an active scan while matching a moving temporal band.
4. Resolve six ordered observations, including a preventable future event and an
   insertion frame from before the encounter.
5. Maintain phase lock, turn inward, and cross under thrust. The player may
   abort before crossing.
6. Traverse the interior worldline toward the selected earlier frame.
7. Brake into the frame and scan to make the exit coherent.
8. Exit into a child branch while the source branch remains recorded.
9. Find the earlier craft, reconstructed from the source branch input history.
10. Hold a directed scan link long enough to transmit the warning.
11. Resolve the mission as a success, preserving both branches and the evidence
    of the run.

## Failure

The slice has explicit recoverable failures:

- Crossing without sufficient coherence ejects the craft to the exterior.
- Overshooting the selected interior frame requires reversing and returning.
- Losing the earlier craft breaks the link but does not erase the branch.
- Structural or coherence depletion ends the run and records a failed outcome.

The first slice does not need combat waves. Weapons remain available as a flight
system test, but the scenario is not accepted until a weapon has a causal role.

## Content Boundary

The slice contains one anomaly, one player craft, one reconstructed earlier
craft, one selected insertion frame, six scan discoveries, one branch fork, and
one communication objective. Additional enemies, campaigns, upgrades, and lore
are outside this milestone.

## Definition Of Playable

- A player can discover the complete loop without a developer console.
- Every transition has an observable prerequisite and an actionable prompt.
- A headless scenario test completes the loop from inputs alone.
- A browser smoke test crosses at least the scanning boundary and verifies that
  the deployed renderer still uses the canonical artifact.
- A full run can be saved, restored, and replayed to the same checksum.
